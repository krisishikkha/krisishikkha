# 📝 Note Maker - Create Beautiful Educational Notes

A powerful, single-page web application for creating, formatting, and exporting beautiful notes with modern UI.

## ✨ Features

### 📋 Core Features
- ✅ **Promotional Tag** - Add catchy tags like "Exam Special"
- ✅ **Title & Subtitle** - Support for main titles with auto-underline
- ✅ **Smart Content Parsing** - Automatically detects:
  - Bullet points (`-`, `•`, `*`)
  - Numbered lists (`1.`, `2.`, etc.)
  - Paragraphs (auto-wrapped)
- ✅ **Footer/Advertisement** - Add contact info or credits
- ✅ **Live Preview** - Real-time preview as you type

### 🎨 Customization
- **Font Control** - Choose different fonts for each section:
  - Arial
  - Noto Sans
  - Roboto
  - Courier New
- **Template Styles**:
  - Minimal (clean, simple)
  - Boxed (with background)
  - Highlight (with colored border)
- **Text Alignment** - Left, Center, Justify
- **Line Spacing** - Adjustable from 1x to 2.5x
- **Logo/Watermark** - Toggle visibility

### 📥 Export Options
- **PNG** - High-quality image export
- **JPG** - Compressed image format
- **PDF** - Professional document format

### 💾 Auto-Save
- Automatically saves your work to browser's localStorage
- Recover your notes if you close the tab
