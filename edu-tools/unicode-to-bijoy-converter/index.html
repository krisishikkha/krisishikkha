📖 How to Use | ব্যবহার পদ্ধতি

  1. Input Text: উপরের বক্সে বাংলা ইউনিকোড টেক্সট লিখুন বা paste করুন
  2. Convert: "Convert to Bijoy" বাটনে ক্লিক করুন
  3. Copy: নিচের বক্স থেকে converted text copy করুন
    • Plain Text: শুধু text copy হবে
    • Rich Text: Font সহ copy হবে (MS Word এ paste করার জন্য)
  4. Paste in MS Word: Word এ paste করলে সঠিক font সহ আসবে
